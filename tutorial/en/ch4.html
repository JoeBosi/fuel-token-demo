The price contract

Goal. Write a minimal oracle: one number, one date and a single person allowed to update it.

Our oracle is a contract that stores three things: the petrol price, the POL price and the time of the last update. Anyone can read; only someone with a specific role can write.

Analogy. It is a blackboard in the square: everyone can see it, but only one person holds the chalk. Next to the price the date is always written.

Two rules about numbers. First: the blockchain has no decimals, so prices are integers multiplied by one million: 1.989 € becomes 1989000. Second: the time comes from the blockchain itself (block.timestamp); the writer does not choose it.

contract FuelPriceOracle is AccessControl {
    bytes32 public constant UPDATER_ROLE = keccak256("UPDATER_ROLE");

    uint256 private _fuelEurPerLitre;
    uint256 private _polEur;
    uint64 private _updatedAt;
    uint64 private _sourceDate;

    constructor(address admin) {
        _grantRole(DEFAULT_ADMIN_ROLE, admin);
    }

    function setPrices(uint256 fuelEurPerLitre, uint256 polEur, uint64 sourceDate)
        external onlyRole(UPDATER_ROLE)
    {
        require(fuelEurPerLitre > 0 && polEur > 0, "zero price");
        _fuelEurPerLitre = fuelEurPerLitre;
        _polEur = polEur;
        _sourceDate = sourceDate;
        _updatedAt = uint64(block.timestamp);
    }

    function fuelPrice() external view returns (uint256, uint64) {
        return (_fuelEurPerLitre, _updatedAt);
    }
}
  • AccessControl is a module from OpenZeppelin: it manages roles.
  • UPDATER_ROLE is the name of the "who may update" role (a label derived from a text).
  • The four private variables are the blackboard: petrol price, POL price, instant of the last update and the data's date (sourceDate, the day the prices refer to).
  • The constructor runs once, at publication, and gives the admin role to whoever publishes.
  • setPrices writes the two prices and the data's date; onlyRole(UPDATER_ROLE) rejects anyone without the role.
  • require rejects a price equal to zero, which would break the divisions in chapter 6.
  • block.timestamp is the time of the block in which the write is recorded.
  • fuelPrice is view: reading is free and needs no signature.

The full project adds the function for the POL price and the freshness check, which the token will use in the next chapters, plus an event (PricesUpdated) that records every update:

function polPrice() external view returns (uint256, uint64) {
    return (_polEur, _updatedAt);
}

function isFresh(uint64 maxAgeSeconds) external view returns (bool) {
    return _updatedAt != 0
        && block.timestamp <= uint256(_updatedAt) + maxAgeSeconds;
}
  • polPrice returns the POL price and the instant, like fuelPrice.
  • isFresh answers "yes" only if prices exist (_updatedAt != 0) and are no older than maxAgeSeconds seconds.

Try it

Open the Remix site (remix.ethereum.org), paste the contract with the OpenZeppelin import lines and pragma solidity ^0.8.24; at the top, compile it and deploy it to Remix's test environment. Then try calling setPrices without the role and watch it get rejected.

What you learned

  • A minimal oracle is a blackboard: values, a date and one authorised writer.
  • Prices are integers with six decimals: 1.989 € is 1989000.
  • isFresh lets other contracts refuse data that is too old.
