The wallet and the test network

Goal. Have MetaMask set up on Polygon Amoy with some test POL.

To use the blockchain you need a wallet: an app that keeps your keys and signs your operations. We will use MetaMask, a browser extension.

Analogy. The wallet is a key ring with a personal stamp. Every blockchain operation is a sheet that becomes valid only when you stamp it, and the stamp never leaves the key ring.

1. Install MetaMask

Download the extension only from the official site (metamask.io), create a wallet and write the recovery phrase on paper. Whoever knows it controls the wallet: never photograph it or share it.

2. Add the Polygon Amoy network

A test network (testnet) works like the real one, but its coin is free and worthless. In MetaMask choose "Add a network manually" and enter:

FieldValue
Network namePolygon Amoy
RPC URLhttps://polygon-amoy-bor-rpc.publicnode.com
Chain ID80002
Currency symbolPOL
Block explorerhttps://amoy.polygonscan.com

Polygon's official RPC address (rpc-amoy.polygon.technology) sometimes does not answer from some servers; the project uses the public PublicNode address, which answered with Chain ID 80002 in our checks. The official addresses remain listed in the Polygon documentation.

The Chain ID is the number that identifies the network: it makes sure the same signature is not valid on another network. The official settings are in the Polygon documentation.

3. Get test POL

A faucet hands out small amounts of test coin. These are the ones we checked as working on 1 November 2026; amounts and rules are those written on their pages and may change.

FaucetAmountWait between requestsRequirements
Chainlink0.5 POL (plus 25 test LINK)not statedjust connect the wallet (MetaMask, WalletConnect or Coinbase Wallet)
QuickNodeshown after you enter the address (doubled with a post on X)12 hoursno account, a small balance on the main network, a verification step
Alchemy0.1 POL24 hoursno account, but at least 0.001 ETH on Ethereum mainnet with some history
GetBlock0.1 POLdailyGetBlock account and at least 0.005 ETH on Ethereum mainnet

For a brand-new wallet the simplest is Chainlink's, because it only asks you to connect the wallet. The official Polygon faucet (faucet.polygon.technology) did not answer our automated checks: try it from a normal browser if the others are not enough.

Try it

Install MetaMask, add Polygon Amoy with the values in the table, then ask the Chainlink faucet for POL. When the MetaMask balance shows "POL" with a number above zero, you are done.

What you learned

  • The wallet keeps the keys and signs: the recovery phrase is never shared.
  • A test network has a free coin; Amoy has Chain ID 80002 and coin POL.
  • A faucet gives a little test coin, with different waits and requirements.
