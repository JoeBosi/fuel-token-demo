FuelToken

Build a token tied to the price of petrol

In nine chapters you build FuelToken: a test digital coin worth one litre of petrol. Every morning the price is read from Italian filling stations and written on the blockchain, so anyone can see where the number comes from.

You do not need to program to follow the ideas: every chapter starts from an everyday picture. If you want to build it, each chapter has a short piece of code and one thing to try, and in an afternoon you reach a working version.

Everything happens on Polygon Amoy, a test network where the coin (POL) is free and worth nothing. That is why you can make mistakes without losing money.

FuelToken is a teaching demo on a test network: the tokens have no real value.

How to use the tutorial

  • Read in order: each chapter builds on the previous one.
  • Always do the "Try it" part: it is the fastest way to understand.
  • The code shown is a simplified version, but the function names are those of the full project.
